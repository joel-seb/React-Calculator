# React Calculator

A minimal calculator app built with React + Vite.

## Setup

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal (usually http://localhost:5173).

## Build

```bash
npm run build
```

## Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit: minimal React calculator"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo-name>.git
git push -u origin main
```

Replace `<your-username>` and `<your-repo-name>` with your GitHub username and the repository name you created.
